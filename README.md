# RestaurantOS-SelfOrderKiosk
A multi-tenant restaurant management platform with a self-ordering kiosk system for small and independent restaurants. Customers can browse multilingual menus and create orders through a tablet kiosk, while restaurant owners manage menus, orders, kiosks, staff, and operations from their own business portal.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
